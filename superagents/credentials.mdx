Sourcetable's credential manager lets you securely store API keys, database passwords, OAuth tokens, and other authentication details. Stored credentials are encrypted and available to the AI when it needs to connect to external services.

## Opening the credential manager

Access credentials from:
- The **credentials button** in the AI chat panel
- **Settings > Credentials** in the sidebar

## Adding credentials

<Steps>
  <Step title="Click Add Credential">
    Opens the credential creation dialog.
  </Step>
  <Step title="Select the service">
    Choose from pre-configured services (Google Analytics, Stripe, etc.) or enter a custom service name.
  </Step>
  <Step title="Choose authentication type">
    Select how the service authenticates:
    - **API Key** — single key (most common)
    - **Bearer Token** — token-based auth
    - **OAuth** — Google/Facebook SSO (automated flow)
    - **Basic Auth** — username + password
    - **Database** — host, port, user, password, database name
    - **HTTP Authentication** — header-based auth
    - **Connection String** — full URI (MongoDB, etc.)
  </Step>
  <Step title="Choose encryption level">
    Select how your credentials are stored:
    - **Standard (symmetric)** — encrypted on the server, no password required each session. Most convenient for daily use.
    - **Maximum security (PGP)** — double-encrypted in browser and on server, password required each session. Best for highly sensitive credentials.
  </Step>
  <Step title="Enter your details">
    Provide a name (alias) for the credential and the authentication fields (API key, password, tokens, etc.).
  </Step>
  <Step title="Save">
    The credential is encrypted and stored. It's now available to the AI and the SQL editor.
  </Step>
</Steps>

## Managing credentials

From the credential manager, you can:

| Action | Description |
|---|---|
| **View** | See credential details (values are masked) |
| **Edit** | Update the alias, service, or authentication details |
| **Refresh** | Re-sync the credential with the external service |
| **Delete** | Permanently remove the credential |

## OAuth credentials

For Google and Facebook services, Sourcetable provides automated OAuth flows:

1. Click the **Google** or **Facebook** button in the Add Credential dialog
2. Complete the OAuth authorization in the popup
3. Tokens are automatically saved and encrypted

Supported OAuth services:
- Google Analytics 4, Google Search Console, Google Ads, Google Drive, Google Sheets, Google Calendar
- Facebook Ads, Instagram Business

## Team credentials

On team and enterprise plans, credentials can be shared with organization members:

- **Team credential access** — grant specific team members access to shared credentials
- **Organization-level management** — admins can view and manage all credentials
- **Credential recovery** — recovery tokens can be generated for emergency access

## Security

- All credentials are encrypted at rest
- PGP credentials are double-encrypted (browser + server)
- Credentials are never sent to AI model providers — only Sourcetable's backend uses them to make API calls
- You can delete any credential at any time

See [security and compliance](/getting-started/security) for more details.
