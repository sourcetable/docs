Sourcetable's AI has access to a library of hundreds of tools, agents, and integrations. These tools extend what the AI can do beyond basic spreadsheet operations.

## Browsing the tool library

Open the tool library from the AI chat panel to browse and search available tools. Each tool includes a description and example usage.

## Free vs. advanced tools

- **Free tools** — available on all plans. Includes most data analysis, visualization, and file processing tools.
- **Advanced tools** — available on Pro and Max plans. Includes premium AI models, advanced integrations, and financial analysis tools.

Use the filter in the tool library to toggle between free and advanced tools.

## Using a tool

You don't need to invoke tools directly. Just describe what you want and the AI selects the right tool:

- "Create a heatmap of correlations" → AI uses matplotlib/seaborn
- "Predict customer churn" → AI uses scikit-learn or TabPFN
- "Scrape product prices from this URL" → AI uses Playwright browser
- "Run a Monte Carlo simulation" → AI uses NumPy/SciPy

To explicitly learn about a specific tool, click it in the tool library and Sourcetable creates a workbook with practical examples.
