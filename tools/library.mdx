Sourcetable's tool library contains hundreds of tools organized into 21 categories. The AI assistant selects the right tools automatically, but you can browse the library to understand what's available.

## Categories

### AI and machine learning
Machine learning models, NLP, text classification, embeddings, and AI-powered analysis. Includes scikit-learn, transformers, Hugging Face Hub, and TabPFN.

### Communications
Send messages, notifications, and integrate with communication platforms. Includes Slack integration.

### Data analysis
Statistical analysis, data profiling, aggregation, and exploratory data analysis. Powered by pandas, SciPy, and StatsModels.

### Data visualization
Charts, graphs, dashboards, and interactive visualizations. Includes matplotlib, plotly, seaborn, bokeh, and ECharts.

### Database
Query databases, manage connections, and process results. Supports 25+ database types through DuckDB, SQLAlchemy, and native connectors.

### Desktop environment
Screenshot capture, browser automation, and computer use capabilities via Playwright.

### Development libraries
Core programming libraries and frameworks for data processing and analysis.

### Development tools
Code execution, debugging, and development utilities. Python and SQL execution engines.

### File processing
Import, export, and transform files. Supports CSV, XLSX, JSON, PDF, and other formats.

### GIS and mapping
Geographic data processing, mapping, and spatial analysis. Create choropleth maps, bubble maps, and population maps.

### Internet and networking
Web search, URL fetching, API calls, and web scraping. Includes Google Search, deep research, and data finder.

### Multimedia and graphics
Image generation, image processing, and visual content creation.

### Science and research
Research tools, academic data sources, and scientific computing utilities.

### Scientific computing
Numerical computing, optimization, and signal processing. Powered by NumPy, SciPy, and specialized scientific libraries.

### Security
Data validation, credential management, and secure data handling.

### System administration
Environment configuration, system monitoring, and resource management.

### Terminals
Command-line execution and shell operations.

### Text processing
Text manipulation, parsing, extraction, regex, and natural language processing. Includes BeautifulSoup and text transformation tools.

### Utilities
General-purpose utilities including date/time handling, format conversion, and data validation.

### Financial AI
25+ institutional-grade financial analysis tools covering fundamental analysis, technical analysis, sentiment analysis, portfolio management, risk management, backtesting, and trade execution. See the [Quant section](/quant/overview) for details.

### Integrations
Direct integrations with Google Analytics, Google Ads, Facebook Ads, Google Search Console, Google Drive, LinkedIn, and TikTok for pulling data directly from these platforms.
