## Data preprocessing

### Handling missing values

- "Fill missing values with the column median"
- "Impute missing data using k-nearest neighbors"
- "Drop rows where more than 50% of values are missing"
- "Forward-fill the time series data"

| Strategy | When to use |
|---|---|
| **Mean/Median imputation** | Numerical columns with few missing values |
| **Mode imputation** | Categorical columns |
| **Forward/backward fill** | Time series data |
| **KNN imputation** | When missing values depend on other columns |
| **Drop rows** | When missing data is random and you have enough rows |

### Encoding categorical variables

- "One-hot encode the product category column"
- "Label encode the priority column (low=1, medium=2, high=3)"
- "Target encode the city column based on average revenue"

### Scaling and normalization

- "Standardize all numeric columns (zero mean, unit variance)"
- "Normalize revenue to a 0-1 range"
- "Apply log transformation to the skewed columns"
- "Use robust scaling on columns with outliers"

| Method | When to use |
|---|---|
| **StandardScaler** | Most ML models, normally distributed data |
| **MinMaxScaler** | When you need values in a specific range (0-1) |
| **RobustScaler** | Data with outliers |
| **Log transform** | Right-skewed distributions |
| **Box-Cox** | General normalization of non-normal data |

## Feature selection

Identify which features matter most:

- "Which columns are most predictive of churn?"
- "Run feature importance on all columns for predicting revenue"
- "Remove columns with less than 5% importance"
- "Check for multicollinearity and drop redundant features"

The AI uses:
- **Correlation analysis** — drop highly correlated features
- **Feature importance** — from Random Forest or Gradient Boosting
- **Variance Inflation Factor (VIF)** — detect multicollinearity
- **Recursive Feature Elimination (RFE)** — iteratively remove the least important features
