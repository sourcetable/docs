Sourcetable brings machine learning to your spreadsheet. Describe what you want to predict or classify, and the AI builds, trains, evaluates, and runs the model.

## TabPFN (zero-shot predictions)

TabPFN is a neural network that makes predictions on tabular data **without training**. It works directly on your spreadsheet data in seconds.

### Predict mode

Select **Predict** from the AI chat mode selector for numerical forecasting:

- "Predict next month's revenue based on the last 24 months"
- "Estimate sale prices for these properties based on size, location, and age"
- "Forecast customer lifetime value from their first 90 days of activity"

### Classify mode

Select **Classify** from the AI chat mode selector for categorization:

- "Classify these leads as hot, warm, or cold based on engagement metrics"
- "Predict which customers are likely to churn"
- "Categorize support tickets by priority level"

## End-to-end ML pipeline

When you ask the AI to build a model, it handles the full pipeline:

<Steps>
  <Step title="Data preprocessing">
    Handles missing values (imputation or removal), encodes categorical variables (one-hot, label encoding), and scales numerical features (StandardScaler, MinMaxScaler).
  </Step>
  <Step title="Train/test split">
    Splits data into training and test sets (typically 80/20) to prevent overfitting.
  </Step>
  <Step title="Model selection">
    Chooses the appropriate algorithm based on your goal, data size, and feature types.
  </Step>
  <Step title="Training">
    Fits the model on training data. For complex problems, uses cross-validation.
  </Step>
  <Step title="Evaluation">
    Returns performance metrics: accuracy, precision, recall, F1-score, ROC-AUC (classification) or R-squared, MAE, RMSE (regression).
  </Step>
  <Step title="Predictions">
    Writes predictions, confidence scores, and feature importance back to your spreadsheet.
  </Step>
</Steps>

## Model evaluation

The AI provides standard evaluation metrics and visualizations:

| Metric | Type | What it tells you |
|---|---|---|
| **Accuracy** | Classification | Overall percentage correct |
| **Precision / Recall** | Classification | True positive rate vs. false positive tradeoff |
| **F1-score** | Classification | Balanced metric combining precision and recall |
| **ROC-AUC** | Classification | Model's ability to distinguish between classes |
| **Confusion matrix** | Classification | Breakdown of predictions vs. actuals |
| **R-squared** | Regression | How much variance the model explains |
| **MAE / RMSE** | Regression | Average prediction error magnitude |
| **Feature importance** | Both | Which columns drive predictions most |
