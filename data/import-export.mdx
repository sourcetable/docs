Sourcetable supports importing and exporting data in several formats.

## Importing data

### Supported import formats
- **XLSX** — Excel workbooks with full formatting and formula support
- **CSV** — comma-separated values
- **JSON** — structured data files
- **PDF** — extract tabular data from PDF documents

### How to import

- **Drag and drop** — drag a file directly into your workbook
- **Upload button** — click the upload button in the toolbar or sidebar
- **AI chat** — attach a file in the AI chat for analysis without importing to the grid
- **Google Drive** — import files from your connected Google Drive

## Exporting data

Export your workbook or specific sheets in these formats:

| Format | Best for |
|---|---|
| **XLSX** | Sharing with Excel users, preserving formulas and formatting |
| **CSV** | Raw data for other tools, databases, or scripts |
| **JSON** | Structured data for APIs and applications |
| **PDF** | Formatted reports for sharing and printing |

## Connecting live data

For data that needs to stay current, use [connectors](/connectors/overview) instead of file imports. Connected data sources refresh automatically, while imported files are static snapshots.
