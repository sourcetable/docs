Sourcetable gives researchers a single environment for data cleaning, statistical analysis, and publication-ready visualization — without switching between Excel, R, and Python.

## What researchers do in Sourcetable

- **Experiment data processing** — clean, normalize, and validate experimental results
- **Statistical analysis** — run t-tests, ANOVA, regression, and non-parametric tests
- **Publication-ready figures** — create charts that meet journal requirements
- **Reproducible analysis** — the AI shows the Python code it runs, so you can reproduce and cite methods

## Example workflows

| Task | How to do it |
|---|---|
| Clean experimental data | Import raw data, ask "Remove outliers, fill missing values, and standardize units" |
| Run statistical tests | Ask "Run a two-way ANOVA on treatment vs. control across three time points" |
| Create a figure | Ask "Generate a box plot with significance markers comparing groups A, B, and C" |
| Correlation study | Ask "Show a correlation matrix with heatmap for all measured variables" |
