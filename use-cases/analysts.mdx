Sourcetable gives analysts a single environment for ad hoc queries, statistical modeling, and recurring reports — without waiting for engineering or switching between tools.

## What analysts do in Sourcetable

- **Ad hoc queries** — ask the AI "What was our top-performing channel last quarter?" and get instant answers from your connected data
- **Statistical models** — run regressions, significance tests, and correlation analysis in natural language
- **Recurring reports** — build live reports that auto-update when underlying data changes
- **Cross-source analysis** — join data from your database, Salesforce, Google Analytics, and spreadsheet files in one place

## Example workflows

| Task | How to do it |
|---|---|
| Pull weekly KPIs from the production database | Connect your database, ask "Show me this week's KPIs" |
| Build a customer segmentation model | Upload customer data, ask "Segment customers by purchase behavior" |
| Create a monthly dashboard | Connect data sources, build charts, enable [automated reporting](/ai/automated-reporting) |
| Run an A/B test analysis | Import experiment data, ask "Is there a significant difference between groups A and B?" |
