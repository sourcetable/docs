Need sample data for testing, demos, or prototyping? Describe the dataset you need, and the AI generates it with realistic values, proper distributions, and consistent relationships between columns.

## Generating synthetic data

Open the AI chat and select **Generate** mode, or ask directly:

- "Generate 500 rows of e-commerce order data with order ID, customer name, product, quantity, price, and date"
- "Create a sample employee directory with 200 entries"
- "Generate financial transaction data with realistic amounts and categories"
- "Make a dataset of 1000 customer support tickets"

## Customization options

You can be specific about the data you want:

- **Row count** — "Generate 100 rows" or "Create 10,000 records"
- **Column types** — specify exact columns and data types
- **Value ranges** — "Prices between $10 and $500"
- **Distributions** — "Revenue should follow a normal distribution with mean $50K"
- **Categories** — "Status should be one of: Active, Inactive, Pending"
- **Relationships** — "Total should equal quantity times unit price"
- **Dates** — "Dates between January 2023 and December 2024"
- **Locale** — "Use US phone numbers and addresses"

## Use cases

- **Testing** — create test data for spreadsheet templates or formulas
- **Demos** — generate realistic-looking data for product demos or presentations
- **Prototyping** — build out a data model with sample data before connecting real sources
- **Training** — create practice datasets for learning formulas, pivot tables, or analysis techniques
- **Privacy** — generate synthetic versions of sensitive data for sharing or development
