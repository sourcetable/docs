Sourcetable's AI can write SQL queries from plain English descriptions. This works both for data already in your spreadsheet and for connected databases.

## Using the SQL generator

Open the AI chat and select **Query** mode, or ask directly:

- "Show me all orders over $1000 from the last 30 days"
- "What's the average revenue by product category?"
- "Find customers who haven't placed an order in 6 months"
- "Join the orders table with the customers table and show the top 10 by total spend"

The AI generates the SQL query, runs it against your data, and returns the results directly in your spreadsheet.

## SQL editor

Sourcetable also includes a built-in SQL editor for writing queries manually:

1. Open the SQL editor from the sidebar or toolbar
2. Write your query
3. Run it against your spreadsheet data or connected databases
4. Results appear in a new sheet or table

The SQL editor supports:

- Standard SQL syntax (SELECT, JOIN, WHERE, GROUP BY, ORDER BY, etc.)
- DuckDB SQL dialect for in-browser queries
- Query builder with visual condition and join editors
- Saved queries in the data library for reuse

## Query builder

For those who prefer a visual approach, the query builder lets you construct queries without writing SQL:

- Select tables and columns
- Add filter conditions with dropdowns
- Configure joins between tables
- Apply Excel-like functions (XL functions)
- Preview results as you build

## Data library

Save frequently used queries to the data library. Saved queries can be:

- Reused across workbooks
- Shared with team members
- Scheduled to refresh on a cadence (with automated reporting)
