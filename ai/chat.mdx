The AI chat is the primary way to interact with Sourcetable's AI. Open it with `Cmd+\` (Mac) or `Ctrl+\` (Windows) and ask questions about your data in plain English.

## How it works

1. The AI reads the data in your spreadsheet (based on your scope settings)
2. You ask a question or give an instruction in natural language
3. The AI responds with numbers, text, formulas, charts, tables, or a combination — whatever fits the question
4. You can follow up with additional questions in the same conversation thread

## Example prompts

**Analysis:**
- "What are the top 5 customers by revenue?"
- "Is there a correlation between marketing spend and new signups?"
- "What's the month-over-month growth rate?"

**Manipulation:**
- "Sort this data by date descending"
- "Remove all rows where status is 'Cancelled'"
- "Add a column that calculates profit margin as (Revenue - Cost) / Revenue"

**Summarization:**
- "Summarize the key trends in this dataset"
- "Give me a one-paragraph executive summary of Q4 performance"

**Generation:**
- "Generate 100 rows of sample e-commerce order data"
- "Create a template for a monthly budget tracker"

## Thread history

Your conversations are saved as threads. Access previous threads from the sidebar in the chat panel. Each thread maintains its context, so you can pick up where you left off.

## Inserting AI responses

When the AI generates data, formulas, or tables, you can insert them directly into your spreadsheet:

- Click the **Insert** button on any AI response to write it into your cells
- Use the **Copy** button to copy the response to your clipboard
- Use the **Download** button to export responses as files

## Attaching files

Click the file upload button in the chat to attach CSV, XLSX, JSON, or other files. The AI can analyze these files directly without you needing to import them into the spreadsheet first.

## Voice input

Click the **microphone button** in the chat input to speak your request instead of typing. Sourcetable uses Whisper speech recognition to transcribe your voice into text.

- Click the mic to start recording
- Speak your question or instruction
- Click again to stop — the transcribed text appears in the input field
- Edit the text if needed, then send

Voice input is useful for longer instructions or when you're analyzing data hands-free.

## Scope selection

By default, the AI has access to data in your active spreadsheet. You can narrow or expand what data the AI sees:

1. Click the **scope button** next to the chat input (or the data source indicator)
2. Select which data sources the AI should use:
   - **Integrations** — connected databases and SaaS tools (select specific integrations and tables)
   - **Files** — attached files in the chat
3. Click **Save** to apply

Narrowing the scope helps the AI focus on the right data and avoids confusion when you have multiple data sources.

## Autopilot mode (alpha)

Autopilot (also called Sheet Agent) is an alpha feature that automates multi-step spreadsheet tasks. Select **Autopilot** from the mode dropdown and describe a complex task:

- "Set up a monthly reporting template with charts for revenue, expenses, and headcount, then populate it with data from the connected database"
- "Clean this dataset, run a segmentation analysis, create a summary dashboard, and export it as PDF"

Autopilot executes multiple steps sequentially without you needing to prompt each one. It's experimental — results may vary for complex workflows.

## Chat modes

The mode selector at the top of the chat lets you focus the AI on specific tasks:

| Mode | What it does |
|---|---|
| **Default** | General-purpose — ask anything |
| **Calculate** | Quantitative analysis and computations |
| **Formula** | Write, explain, or fix spreadsheet formulas |
| **Chart** | Create charts and visualizations |
| **Query** | Write and run SQL queries |
| **Modify** | Transform, clean, or restructure data |
| **Generate** | Create sample data and templates |
| **Analyze** | Data analysis and insights |
| **EDA** | Exploratory data analysis |
| **Predict** | TabPFN predictions (numerical) |
| **Classify** | TabPFN classifications (categorical) |
| **Autopilot** | Multi-step task automation (alpha) |
| **Template** | Formatted table generation (alpha) |
| **Public Dataset** | Find and import public datasets (alpha) |

## Selecting a model

Pro and Max plan users can choose which AI model powers their chat. Click the model selector dropdown to switch between available models. See [AI models](/reference/ai-models) for the full list.
