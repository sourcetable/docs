Combine multiple charts, tables, and KPIs into a dashboard view. Dashboards update automatically when the underlying data changes.

## Building a dashboard

### With AI

Ask the AI to create a complete dashboard:

- "Build a sales dashboard with revenue trend, top products, pipeline funnel, and regional breakdown"
- "Create an executive dashboard showing MRR, churn rate, CAC, and LTV with trend charts"
- "Make a marketing dashboard with campaign performance, conversion rates, and channel attribution"

The AI creates multiple charts and arranges them in a logical layout.

### Manually

1. Create individual charts from your data
2. Arrange them on a dedicated dashboard sheet
3. Add KPI cells with summary formulas at the top
4. Use conditional formatting to highlight targets and thresholds

## Live dashboards

When your charts reference connected data sources (databases, APIs, SaaS integrations), your dashboard updates automatically as the source data changes. This means:

- Sales dashboards reflect the latest CRM data
- Marketing dashboards show real-time campaign metrics
- Financial dashboards pull current accounting data

## Publishing

Publish individual charts to create shareable links. Published charts display the latest data, so recipients always see current information without needing a Sourcetable account.

## Dashboard examples

| Use case | Key metrics | Data sources |
|---|---|---|
| **Sales** | Revenue, pipeline value, win rate, avg deal size | Salesforce, HubSpot, Stripe |
| **Marketing** | CAC, conversion rate, campaign ROI, channel mix | Google Ads, Facebook Ads, GA4 |
| **Finance** | Revenue, expenses, margin, cash flow, budget variance | QuickBooks, Xero, Stripe |
| **Operations** | SLA compliance, throughput, capacity, backlog | Jira, Zendesk, custom databases |
| **Product** | DAU, retention, feature adoption, NPS | Amplitude, FullStory, Segment |
| **E-commerce** | Orders, AOV, cart abandonment, inventory | Shopify, WooCommerce, Stripe |
