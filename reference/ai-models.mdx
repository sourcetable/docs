Sourcetable uses multiple AI models to power its assistant. The default model is selected automatically, but Pro and Max plan users can choose their preferred model.

## Available models

| Model | Provider | Notes |
|---|---|---|
| **Sourcetable Default** | Sourcetable | Optimized for spreadsheet tasks, selected automatically |
| **GPT-4** | OpenAI | Strong general-purpose reasoning |
| **Claude 3.5 Sonnet** | Anthropic | Excellent at analysis and long-context tasks |
| **Llama 3.3 70B** | Meta (via Groq) | Fast inference, good for quick tasks |

## Selecting a model

1. Open the AI chat panel (`Cmd+\` / `Ctrl+\`)
2. Click the model selector dropdown at the top of the chat
3. Choose your preferred model

The selected model persists across sessions until you change it.

## Model availability by plan

| Plan | Models |
|---|---|
| **Free** | Sourcetable Default (with message limits) |
| **Pro** | All models, expanded chat memory and context |
| **Max** | All models, maximum chat memory and context, unlimited messages |
| **Enterprise** | All models with custom configurations |

## AI credits

Some AI operations consume credits. Free plan users have limited credits per month, while Pro users have expanded limits and Max users have unlimited usage (subject to abuse guardrails).

You can purchase additional AI credits from your account settings if you need more on the Pro plan.
