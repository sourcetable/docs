Sourcetable has full formula parity with Excel and Google Sheets. Any formula that works in Excel works in Sourcetable.

### Statistical

### Lookup and reference

### Financial

## Array formulas

Sourcetable supports array formulas for operations that return multiple values. Enter an array formula by pressing `Ctrl+Shift+Enter` after typing the formula.

## Dynamic arrays

Functions like `XLOOKUP`, `FILTER`, `SORT`, `UNIQUE`, and `SEQUENCE` can spill results into multiple cells automatically.

## Cross-sheet references

Reference cells on other sheets using the `SheetName!CellReference` syntax:

```
=Sheet2!A1
=SUM(Sales!B2:B100)
=VLOOKUP(A2, 'Customer Data'!A:C, 3, FALSE)
```

Use single quotes around sheet names that contain spaces.
