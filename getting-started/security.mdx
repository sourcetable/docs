Sourcetable is built on infrastructure and tooling that meets the standards required by security-conscious organizations.

## Data encryption

All data in Sourcetable is encrypted:

- **Encrypted at rest** — your data is encrypted when stored
- **Encrypted in transit** — all connections use TLS/HTTPS
- **Private user keys** — an additional encryption layer where credentials are encrypted with keys that only you control

## Credential security

When you add API keys, database passwords, or OAuth tokens to Sourcetable, you choose between two encryption modes:

| Mode | How it works | Best for |
|---|---|---|
| **Standard (symmetric)** | Encrypted on the server. No password required each session. | Convenience — most users |
| **Maximum security (PGP)** | Double-encrypted in browser and on server. Password required each session. | Maximum protection — sensitive credentials |

See [credential management](/superagents/credentials) for details on adding and managing credentials.

## Infrastructure

Sourcetable's infrastructure is built on services and providers that maintain SOC 2, HIPAA, and PCI compliance certifications:

- Cloud hosting on SOC 2-certified infrastructure
- Database services with encryption at rest and in transit
- Authentication providers with enterprise-grade security standards
- Monitoring and logging through compliance-certified observability platforms

## Enterprise security features

Enterprise plans include additional security capabilities:

- **SSO (Single Sign-On)** — SAML/OIDC integration with your identity provider
- **Centralized team billing** — manage all seats from one account
- **Advanced permissions** — granular access controls
- **Dedicated support** — priority support with white-glove onboarding

## Data handling

- Sourcetable does not train AI models on your data
- Connected database credentials are encrypted and stored securely
- You can delete your data and account at any time
