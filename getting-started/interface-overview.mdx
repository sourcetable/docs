Sourcetable's interface combines a familiar spreadsheet layout with an AI assistant panel and data connection tools.

## Main areas

### Toolbar

The toolbar at the top provides quick access to formatting options, formula tools, and actions. Key elements include:

- **Formula bar (Fx)** — view and edit the formula or value in the selected cell
- **Format controls** — bold, italic, underline, text color, background color, borders, number formats
- **Insert** — add rows, columns, charts, and pivot tables
- **Actions** — open the command bar for AI-powered quick actions

### Spreadsheet grid

The main workspace where you enter, view, and manipulate data. It supports:

- Multiple sheets via the tab strip at the bottom
- Freeze panes for rows and columns
- Cell selection with keyboard and mouse
- Drag-to-fill for patterns and sequences
- Right-click context menus for common operations

### AI chat panel

Press `Cmd+\` (Mac) or `Ctrl+\` (Windows) to toggle the AI assistant panel. The chat panel includes:

- **Thread history** — access previous conversations in the sidebar
- **Mode selector** — choose a specialized mode like Calculate, Formula, Chart, Query, Modify, Generate, Analyze, or EDA
- **Scope selector** — control which data the AI can see (current sheet, specific range, or connected data sources)
- **Voice input** — click the microphone button to speak your request
- **File upload** — attach files directly in the chat for analysis

### Command bar

Press `Cmd+K` (Mac) or `Ctrl+K` (Windows) to open the command bar. This provides instant access to AI-powered actions without opening the full chat panel:

- Clean data
- Remove duplicates
- Generate or fix formulas
- Summarize data
- Autofill cells
- Sort, filter, and format

### Data sidebar

The right sidebar provides access to your data and settings. Open it with `Cmd+Shift+\` (Mac) or `Ctrl+Shift+\` (Windows), or click the sidebar icon in the toolbar.

- **Workbooks** — navigate between your workbooks
- **Data library** — saved queries and data sources
- **Connectors** — manage your connected databases and APIs
- **Settings** — account, organization, and workbook settings

## Keyboard shortcuts
