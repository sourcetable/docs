Model Context Protocol (MCP) connectors let you connect Sourcetable to any MCP-compatible server. This extends the AI assistant's capabilities by giving it access to external tools and data sources.

## What is MCP

MCP (Model Context Protocol) is a standard for connecting AI assistants to external tools and data. When you connect an MCP server, the AI assistant gains access to the tools and data that server provides.

## Available MCP connectors

- **Apify** — web scraping, data extraction, and browser automation

## Adding an MCP connector

<Steps>
  <Step title="Add a connector">
    Click **Add Connector > MCP** and select the MCP server.
  </Step>
  <Step title="Authenticate">
    Provide your bearer token or API key for the MCP server.
  </Step>
  <Step title="Use the tools">
    The AI assistant can now use the tools provided by the MCP server. Ask it to perform actions like web scraping or data extraction.
  </Step>
</Steps>

## Superagents

Sourcetable's Superagents feature extends connectivity further:

- **API Playground** — add third-party API keys and database credentials to give the AI access to external services
- **Tool Library** — hundreds of built-in tools and agents organized across 21 categories including data analysis, visualization, scientific computing, security, and more
- **Premium Connectors** — built-in database and app connectors
- **Writeback (beta)** — orchestrate actions across connected services from your spreadsheet
